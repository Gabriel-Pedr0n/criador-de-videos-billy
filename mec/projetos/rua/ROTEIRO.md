## Bloco 1 — Gancho + subleito  (60 palavras, ~18 s)

```
Se você jogar asfalto direto em cima da terra, você não vai ter uma rua. Vai ter uma fábrica de buracos. Porque a terra fofa afunda com o peso dos carros, e o asfalto quebra junto, como casca de ovo. Então você raspa a terra solta e passa um rolo pesado até o chão ficar duro. Esse é o subleito.
```

## Bloco 2 — Base de pedra  (64 palavras, ~20 s)

```
Mas quando chove, até terra dura amolece, e as rodas de um caminhão afundam nela. Então você cobre tudo com uma camada grossa de pedra britada, bem socada, que espalha o peso como uma tábua em cima da lama. Essa é a base. É por isso que o buraco sempre volta no mesmo lugar: o remendo tapa o asfalto, mas a base continua mole.
```

## Bloco 3 — Imprimação + asfalto quente  (67 palavras, ~21 s)

```
Mas asfalto não gruda em pedra solta e cheia de pó. Então você rega a base com um asfalto ralo, quase líquido, que entra entre as pedras e cola tudo. Essa é a imprimação. Mas a capa só se molda quente. Então você mistura pedra com asfalto derretido, espalha a mais de cem graus e aperta com o rolo antes de esfriar. Esse é o concreto asfáltico.
```

## Bloco 4 — Água: abaulamento, sarjeta e boca de lobo  (72 palavras, ~22 s)

```
Mas água parada entra em qualquer trinca e apodrece a rua por baixo. Então você faz o meio mais alto que as beiradas, pra chuva escorrer pros lados. Esse é o abaulamento. E na beira, uma canaleta de concreto leva a água até uma abertura que engole a enxurrada. Essa é a sarjeta e essa é a boca de lobo. É por isso que, quando ela entope de lixo, a rua alaga.
```

## Bloco 5 — Humor + parabéns + comente  (44 palavras, ~16 s)

```
Coloque faixas, uma placa de pare e um quebra-molas que ninguém pintou. Agora é só ligar o carro e passar por cima. Parabéns, você asfaltou uma rua. Se você já sabia, comente engenheiro. Se não sabia, comente motorista. E segue o Mundo em Camadas.
```
