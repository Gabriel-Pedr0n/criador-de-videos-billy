## Bloco 1 — Cofre  (71 palavras, ~25 s)

```
Se você deixar o dinheiro do caixa eletrônico numa gaveta atrás da tela, você não vai ter um caixa eletrônico. Vai ter um presente para o primeiro pé de cabra. Porque a máquina fica na rua, dia e noite, sem ninguém olhando. Então você coloca o dinheiro numa caixa de aço grosso, chumbada no chão. Por fora, só a tela, o teclado e a boca das notas. Esse é o cofre.
```

## Bloco 2 — Cassetes  (62 palavras, ~23 s)

```
Mas se as notas ficarem soltas lá dentro, a máquina não sabe quanto entregar. Então você separa em gavetas fechadas, uma para cada nota: cinquenta, cem e duzentos. Uma ventosa puxa uma nota de cada vez e solta numa esteira. Essas são as cassetes. É por isso que o caixa às vezes avisa que não tem nota de cinquenta: aquela gaveta acabou.
```

## Bloco 3 — Rejeito  (61 palavras, ~21 s)

```
Mas e se duas notas vierem grudadas? Você saca cem e leva duzentos. Então você passa cada nota entre dois roletes que medem a grossura. Grossa demais, a máquina não entrega: desvia para uma caixa trancada que só o banco abre. Essa é a caixa de rejeito. É por isso que às vezes o caixa conta, para e conta de novo.
```

## Bloco 4 — Tinta  (52 palavras, ~19 s)

```
Mas e se alguém arrombar o cofre? Então você coloca um cartucho de tinta em cada cassete. Se a gaveta for aberta à força, a tinta estoura e mancha todas as notas. E nota manchada assim perde o valor: o banco recolhe e ninguém é reembolsado. Esse é o sistema de entintamento.
```

## Bloco 5 — Final  (58 palavras, ~22 s)

```
Mas ainda falta o lado de fora. Então você coloca a tela, a câmera e um teclado com um pontinho no cinco, para quem não enxerga. Coloque também um adesivo de aviso que ninguém lê. Agora é só passar o cartão. Parabéns, você montou um caixa eletrônico. Se você já sabia, comente CASSETE. Se não sabia, comente TINTA.
```
