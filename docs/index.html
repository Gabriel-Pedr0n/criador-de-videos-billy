Conexão

Como criar o token (1 minuto)
  1. GitHub → foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → escolha só este repositório.
  3. Permissions: Actions = Read and write e Contents = Read-only.
  4. Copie o token e cole acima. Ele só dispara e lê este workflow; as chaves do Claude e da ElevenLabs ficam nos Secrets do repositório, nunca nesta página.
